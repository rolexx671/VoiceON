# Локальные проверки без XCTest

Запуск из корня проекта:

```bash
bash scripts/test-local.sh
```

Скрипт нужен для Mac, где установлены только Command Line Tools и отсутствует модуль XCTest. Он компилирует исходники библиотеки VoiceON и вызывает синхронные тестовые методы из настоящих файлов Tests/OpenWisprTests. Копии тестов создаются во временном каталоге; исходные файлы не меняются. Для каждого метода создаётся новый экземпляр теста и вызываются его методы подготовки и завершения.

Адаптер поддерживает только используемые в проекте синхронные утверждения. Генератор отказывает при обнаружении неподдерживаемых сигнатур, асинхронных ожиданий и отдельных специальных API XCTest. Это дополнительная локальная проверка; полноценный запуск с Xcode выполняется командой `swift test`.

ModelAvailabilityTests исключён явно: он проверяет доступность всех моделей по HTTP. Скрипт не заменяет эту сетевую проверку, реальное распознавание микрофона, работу интерфейса, разрешений macOS или ручную установку из DMG. Тесты аудиоформатов создают временные WAV-файлы; остальные побочные действия ограничены уже существующими тестами.
